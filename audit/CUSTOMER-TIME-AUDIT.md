# Customer timezone display — 6.12.10

The cart previously rendered cb_meeting_time verbatim even though it contains the UTC ISO slot. Product availability tiles and date grouping prioritized the site's timezone. These now use the browser's timezone and show a formatted local date/time rather than ISO UTC strings.

A validated IANA timezone, including recognized backwards-compatible names, is captured in cb_timezone and persisted as line-item _cb_booking_timezone, order _cb_timezone and the booking snapshot. The Scheduling API receives that timezone on the invitee while start_time remains the exact selected UTC instant. Email token dates and meeting detail tables use the saved customer's timezone or the persisted Calendly invitee timezone, never the event/host timezone in preference to the invitee.

A shared customer-time script supplies the browser timezone, updates checkout hidden fields, and formats marked time elements on cart/checkout, confirmation, order and account pages. Account SQL timestamps receive an explicit UTC offset before browser parsing. Client conversion handles date rollover and daylight saving automatically. The timezone cookie lets server rendering use the current viewer's timezone; unknown historical booking timezones fall back to the site timezone until browser formatting applies. Emails for old bookings with neither captured timezone nor Calendly invitee timezone cannot recover the original customer timezone.

Validation: ten PHP timezone checks and five client DOM formatter checks passed, including Los Angeles summer/winter offsets, previous-day conversion, cart suppression of ISO values, persisted timezone, invitee API timezone with unchanged UTC start, email preference over host timezone, cookie validation, and explicit UTC SQL conversion. The existing 112 booking/checkout/API/availability/dashboard/export checks also passed (127 total). All plugin PHP and JavaScript sources passed syntax checks. Browser checks use a DOM fixture, not a full live browser. No live bookings or customer emails were sent.
